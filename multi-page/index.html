Sobre o Desafio

O Do Well Do Good Challenge é uma competição de estudo de caso que reúne os melhores estudantes para criar soluções duradouras para problemas de impacto social. Nesta edição, desafiamos-te a desenvolver soluções criativas para um problema relacionado com XXX, fornecido pelo nosso parceiro XXX. Todos os problemas e dados serão fornecidos pelo nosso parceiro principal, XXX, orientados para estratégias de otimização energética para uma instalação mais sustentável.
